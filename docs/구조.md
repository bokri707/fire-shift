# 코드 구조

## 데이터가 저장되는 곳
| 내용 | 위치 |
|---|---|
| 내 근무 형태·기준일, 맞교대·연가 기록, 메모, 별명, 알림 설정 | **폰 안** (AsyncStorage, 키 `fire-shift-rn-v1`) |
| 소모임 팀원의 근무·연가·교육, 투표, 팀 일정 | **서버** (Supabase) |
| 맞교대 상대 이름, 메모 | 폰 안에만 있고 서버로 보내지 않음 |

폰을 바꾸면 폰 안 데이터는 사라집니다. 그래서 설정 화면에 백업(복사/붙여넣기) 기능이 있습니다(`src/lib/backup.ts`).

## 상태 (`src/store.tsx`, `src/types.ts`)
- 상태 전체가 `AppState` 하나입니다. 불러올 때 `{ ...기본값, ...저장값 }`으로 합치므로 새 필드는 옵션으로 추가하면 옛 저장값과 호환됩니다.
- `update(fn)`으로만 바꿉니다. 저장은 300ms 뒤 자동입니다.
- `markWrite()`: 서버에 쓴 직후 서버 응답이 방금 입력을 덮어쓰지 않게 하는 장치입니다.

## 겉으로 안 보이는 약속
1. **팀 일정은 투표 항목입니다.** 서버 구조를 바꾸지 않으려고 `polls`에 제목 앞 말머리(`[일정]` 등)를 붙이고 `final`이 있는 항목을 "일정"으로 취급합니다. (`src/lib/events.ts`의 `parseEvent`, `eventsByDate`) 말머리가 없는 확정 항목은 "모임"입니다. 홈 화면의 모임 목록·알림에서는 일정을 뺍니다(`allMeets`).
2. **팀원의 `ex`**: 날짜→상태 문자열 맵. `_p`는 인코딩된 근무 패턴, `b:날짜`는 직접 입력 근무입니다.
3. **3교대 동료 계산**: 내가 3교대면 `base3`(1팀이 당직인 기준일)로 다른 팀 근무를 계산합니다.
4. **탭 표시 규칙 (`App.tsx`)**: 달력·설정은 항상. **팀**은 `teamOn` 또는 근무 팀(kind=team) 가입 또는 초대 링크로 들어왔을 때. **모임**은 `meetOn` 또는 모임(kind=meet) 가입. 부부·육아 탭은 없앴습니다(육아시간은 홈 달력의 점으로 표시). 예전 사용자가 소모임에 들어가 있으면 불러올 때 `teamOn`을 켭니다(`store.tsx`).
4-1. **소모임 종류**: 서버 `teams.kind`(team/meet)가 기준이고 동기화 때 각 소모임에 반영됩니다(`CloudSync`). 팀 탭은 근무 팀만, 모임 탭은 모임만 다룹니다(`TeamScreen kind=...`). 모임은 연가 한도·보강·육아시간 없이 일정·투표만 보여줍니다(`CoupleCard`의 `plan` 플래그). 탭을 누르면 그 종류의 소모임으로 자동 전환(`focusKind`)하고, 종류를 바꾸면 해당 탭으로 옮겨 갑니다.
4-2. **배우자를 찾는 소모임**(홈 달력의 육아시간 파란 점, 가족 소모임의 부부 달력): 지금 보는 소모임과 상관없이 `pairCode`(이 폰에서 고른 것) → 서버에 부부(가족)로 표시된 소모임(`pair`) → 사람이 있는 모임 → 지금 소모임 순서로 정한 소모임에서 배우자를 찾습니다. 설정 탭의 "기능 켜기"에서 바꿉니다(`pairGroupCode`·`spouseOf`, `store.tsx`). 홈 달력 점: 내 육아시간 주황, 배우자 파랑, 왼쪽=출근 때·오른쪽=퇴근 때(`MonthCalendar.tsx`). 부부(가족)로 표시한 소모임의 "모임 일정"은 나와 배우자 근무를 한 달력에 겹쳐 보이는 틀을 씁니다(`CoupleCard.tsx`의 `TeamView` `partner`).
5. **스와이프**: `PanResponder`로 가로 이동이 세로의 1.5배 이상이고 20px를 넘을 때만 잡습니다. 웹은 `touchAction: 'pan-y'`. 홈 달력, 팀 근무표(7일/30일), 연가계획표, 부부 달력에 있습니다.
6. **7일 보기**는 오늘이 맨 왼쪽, 이후 6일입니다.

## 동기화 (`src/CloudSync.tsx`)
- 앱이 화면에 보일 때만 서버를 확인합니다. 간격은 탭별로 다릅니다(팀 6초, 부부 30초, 달력 45초, 설정 없음).
- 서버가 내용 해시를 비교해 바뀌지 않았으면 데이터를 보내지 않습니다(`fetch_team_v2`).
- 내 근무 정보가 바뀌면 들어가 있는 모든 소모임에 올립니다.

## 사용 횟수 (`src/lib/usage.ts`)
`bump('open'|'cal'|'team'|'pair'|'set')`이 서버 함수 `bump_usage`를 호출해 하루 합계만 올립니다. 실패해도 앱에는 영향이 없고, 서버에 함수가 없으면(404) 이후 호출을 멈춥니다.
