# 개인정보처리방침 (초안)

> 이 문서는 실제 앱 동작(코드·`supabase/schema.sql`)을 보고 썼습니다. 앱 기능이 바뀌면 같이 고치세요.
> 시행일: 2026-11-01

"소방 교대달력"(이하 "앱")은 이용자의 개인정보를 꼭 필요한 만큼만 다룹니다.

## 1. 앱에서 다루는 정보

앱은 **회원가입과 로그인이 없습니다.** 이메일, 전화번호, 주소, 생년월일, 주민등록번호는 받지 않습니다.

### 가. 내 폰(또는 브라우저)에만 저장되는 정보
- 근무 형태, 기준일, 연가·교육·육아시간 등 개인 일정과 메모, 설정
- 알림 시각 설정. 근무 전날 알림은 폰 안에서만 예약되며, **알림을 위해 서버로 보내는 정보는 없습니다.**
- 위 정보는 이용자가 앱을 지우거나 데이터를 삭제하면 함께 사라집니다.

### 나. 소모임을 쓸 때 서버에 저장되는 정보
소모임(팀, 모임, 부부 함께 보기)을 만들거나 가입하면 아래 정보가 서버(Supabase)에 저장됩니다.
- 소모임 코드와 소모임 이름, 근무 기준일, 소모임 종류
- 팀원 이름(이용자가 직접 입력한 이름 또는 별명), 팀 번호, 연가·교육·육아시간 등 일정 정보
- 모임·투표 제목, 후보 날짜, 투표 결과
- 소모임 코드를 아는 사람은 그 소모임의 위 정보를 볼 수 있습니다. **이름은 실명이 아닌 별명을 써도 됩니다.**

### 다. 서버가 자동으로 남기는 정보
- **사용 횟수 합계:** 날짜별로 "앱 열기, 달력, 팀, 부부·육아, 설정" 탭 사용 횟수의 합계만 모읍니다. 누가 눌렀는지, 어떤 기기인지는 저장하지 않습니다.
- **소모임 코드 추측 방지 기록:** 존재하지 않는 소모임 코드를 조회하면 접속 주소(IP)와 입력한 코드를 **되돌리기 어려운 값(해시)**으로 바꿔 남깁니다. 원래 주소와 코드는 저장하지 않습니다. 이 기록은 **1시간이 지나면 지우는 대상**이며, 새로운 잘못된 조회가 생길 때 함께 정리됩니다. 이 값은 무작위 대입 공격을 막는 데만 씁니다.

### 라. 광고(구글 AdMob)
- 앱 아래에 구글 AdMob 배너 광고가 표시됩니다.
- 광고를 보여주고 부정 클릭을 막기 위해 구글이 기기의 **광고 ID**, 접속 주소(IP) 등을 처리할 수 있습니다. 앱은 **맞춤 광고를 끄고**(비개인화 광고) 광고 등급을 낮게(PG 이하) 요청합니다.
- 자세한 내용은 구글 안내를 따릅니다: https://policies.google.com/technologies/ads
- 폰 설정에서 광고 ID를 삭제하거나 맞춤 광고를 끌 수 있습니다. (안드로이드: 설정 → Google → 광고)

## 2. 이용 목적
- 근무표와 일정을 보여주고 알림을 드리기 위해
- 소모임 안에서 근무·일정·투표를 함께 보기 위해
- 앱이 얼마나 쓰이는지 파악해 개선하기 위해(합계 통계)
- 무차별 대입 공격으로부터 소모임을 보호하기 위해
- 광고를 표시하기 위해

## 3. 보관 기간과 삭제
- 내 폰에 저장된 정보: 앱을 지우거나 앱 데이터를 삭제할 때까지
- 서버의 소모임 정보: 소모임을 지우면 팀원·투표 정보가 함께 지워집니다. 본인이 올린 팀원 정보는 앱의 **"이 소모임에서 나가기"**로 삭제할 수 있습니다. "모든 기록 초기화"는 내 폰의 기록만 지웁니다. 통신 상태 등으로 삭제가 안 됐거나 앱에서 지울 수 없는 경우는 아래 문의처로 요청하세요.
- 사용 횟수 합계: 개인을 알아볼 수 없는 숫자라 계속 보관합니다.
- 코드 추측 방지 기록: 1시간이 지나면 삭제 대상이 되며, 새로운 잘못된 조회가 있을 때 정리

## 4. 개인정보 제3자 제공과 처리 위탁
- 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다.
- 서비스 운영을 위해 아래 업체의 서비스를 씁니다.

| 업체 | 하는 일 | 처리 항목 |
|---|---|---|
| Supabase | 서버·데이터 저장 | 3-나, 3-다 항목 |
| Cloudflare | 웹 앱 배포·전달 | 웹 접속 시 접속 주소 등 통신 정보 |
| Google AdMob | 광고 표시 | 1-라 항목 |
| Expo | 앱 빌드·배포 도구 | 이용자 정보 처리 없음(개발 과정에서만 사용) |

- 위 업체의 서버는 해외에 있을 수 있습니다. 이 경우 해외로 전달되는 정보는 위 표의 처리 항목에 한하며, 서비스 제공과 운영 목적으로만 쓰입니다.

## 5. 이용자의 권리
이용자는 언제든지 자신의 정보를 보거나, 고치거나, 지워 달라고 요청할 수 있습니다. 앱에서 직접 할 수 없는 것은 아래 문의처로 연락해 주세요.

## 6. 안전을 위한 조치
- 서버의 모든 표에 행 단위 보안(RLS)을 켜서 직접 접근을 막고, 정해진 함수로만 접근하게 했습니다.
- 소모임 코드를 무작위로 대입해 알아내려는 시도는 접속 주소 기준으로 제한합니다.
- **소모임 코드는 사실상 비밀번호입니다.** 모르는 사람에게 알려 주지 마세요.

## 공개 전 확인 목록 (대표님용, 공개 문서에는 넣지 않음)
1. 시행일, 담당자, 문의 이메일을 채운다.
2. 이 방침을 **누구나 열 수 있는 주소**에 올린다. 구글 플레이 등록에는 공개 주소(URL)가 필요하다. (예: 웹 앱의 한 페이지 또는 GitHub 공개 페이지. 올리기 전에 어디에 둘지 먼저 정한다.)
3. 구글 플레이의 "데이터 보안" 설문을 이 문서와 똑같이 적는다: 기기 또는 기타 ID(광고 ID), 앱 활동(사용 횟수), 이름(별명), 일정 정보.
4. 해외 서버 이용(국외 이전) 문구는 법률 전문가나 공식 안내로 한 번 확인한다.
