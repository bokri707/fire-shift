# 운영

## 배포 (Cloudflare Workers)
- GitHub `bokri707/fire-shift`의 `main`에 올리면 Cloudflare Workers Builds가 자동으로 빌드·배포합니다. (주소: https://fire-shift.qkrrhksdud1.workers.dev)
- 빌드 명령: `npx expo install react-dom react-native-web @expo/metro-runtime && npx expo export --platform web`
- 배포 명령: `npx wrangler deploy`
- 빌드 변수: `NODE_VERSION=22`
- 설정 파일: `wrangler.jsonc` (`./dist` 폴더를 정적 파일로 배포, 없는 주소는 `index.html`로 보냄)
- 설정을 바꾸는 곳: Cloudflare 대시보드 → Workers 및 Pages → fire-shift → 설정 → 빌드
- 배포 결과 확인: 저장소의 커밋 옆 체크 표시 또는 Cloudflare 대시보드의 빌드 기록. 올린 뒤 2~3분 걸립니다.
- 폰 브라우저에 예전 화면이 남아 있으면 새로고침하거나 탭을 닫고 다시 여세요.
- `netlify.toml`은 예전 Netlify 배포 설정입니다. (크레딧 소진으로 Cloudflare로 옮김. 지워도 됩니다.)

## 장애 대응
| 증상 | 먼저 볼 것 |
|---|---|
| 웹이 안 열림 | Cloudflare 대시보드의 배포 상태, 무료 한도 초과 여부 |
| 최신 화면이 안 나옴 | 배포가 끝났는지(커밋의 체크 표시), 폰 새로고침 |
| 소모임 데이터가 안 불러와짐 | Supabase 프로젝트가 일시 중지됐는지(무료 플랜은 장기간 미사용 시 중지), 대시보드 로그 |
| 통계가 안 올라감 | `bump_usage` 함수 존재 여부, 앱 화면에 오류는 안 뜸(조용히 무시) |
| 빌드 실패 | Cloudflare 빌드 로그. 과거에 react-dom 누락으로 실패한 적 있어 빌드 명령에 `expo install`이 들어 있음 |
