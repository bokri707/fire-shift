# 사용 횟수 통계

## 무엇을 모으나
하루 단위 **합계만** 모읍니다. 누가 눌렀는지, 어떤 기기인지는 저장하지 않습니다.

| kind | 뜻 |
|---|---|
| open | 앱을 열었거나 다시 화면에 나온 횟수 |
| cal | 달력 탭을 누른 횟수 |
| team | 팀·모임 탭을 누른 횟수 |
| pair | 부부·육아 탭을 누른 횟수 |
| set | 설정 탭을 누른 횟수 |

날짜는 한국 시간 기준입니다. 표는 `usage_daily(day, kind, n)`.

## 보는 방법 (Supabase 대시보드 → SQL 편집기)
```sql
-- 최근 14일 일별
select day, kind, n from usage_daily where day >= current_date - 14 order by day desc, kind;

-- 일별 앱 열기 횟수
select day, n from usage_daily where kind = 'open' order by day desc limit 30;

-- 탭 비중(최근 30일)
select kind, sum(n) from usage_daily where day >= current_date - 30 group by kind order by 2 desc;
```

## 한계
- 사람 수가 아니라 **횟수**입니다. 월 활성 이용자(MAU)나 재방문율은 이 표로 알 수 없습니다.
- 앱을 열 때마다 `open`이 올라가므로 한 사람이 여러 번 열면 그만큼 늡니다.
- 누구나 함수를 호출할 수 있어서 조작될 수 있습니다.
- 사람 수를 알려면 기기별 익명 번호를 하루 한 번만 세는 방식이 따로 필요합니다. (개인정보 처리방침에 반영해야 함)
