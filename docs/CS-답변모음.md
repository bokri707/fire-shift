# 소방 교대달력 CS 답변 모음

- 작성: CS부 / 기준일: 2026-11-01
- 대상: 소방 교대달력 (안드로이드 앱 `kr.fireshift.app`, 웹 주소 https://fire-shift.fire-shift-app.workers.dev)
- 근거: 앱 코드(`src/`, `App.tsx`, `supabase/schema.sql`)와 `docs/` 문서. 코드에서 확인하지 못한 것은 "확인 필요"로 적었습니다.

> **맨 위 주의: 이 문서의 모든 답변은 초안입니다. 사용자에게 보내기 전에 대표 승인이 필요합니다.** 구글 플레이 리뷰 답글도 대표 승인 후에만 올립니다. 개인정보, 환불, 보상, 법 문제, 기록 복구는 CS부가 답하지 않고 팀장에게 바로 넘깁니다.

## 0. 앱이 실제로 하는 일 (답변할 때 지켜야 할 사실)

- 회원가입, 로그인, 전화번호 입력이 없습니다.
- 내 근무 설정, 연가·교육 기록, 메모, 알림 설정은 **폰 안에만** 저장됩니다. 폰을 바꾸거나 앱을 지우면 사라집니다. (`docs/구조.md`)
- 소모임(팀·모임)에 들어가면 별명, 근무·연가·교육 정보, 투표 내용이 **서버에 올라갑니다.** 소모임 코드를 아는 사람은 그 내용을 볼 수 있어서, 코드는 사실상 비밀번호입니다. (`docs/서버.md`)
- 근무 알림과 모임 알림은 **폰 안에서 예약**됩니다. 근무 알림은 앞으로 14일치이고, 앱을 열 때마다 다시 예약합니다. 오랫동안 앱을 열지 않으면 그 뒤 알림이 오지 않습니다. (`src/DutyNotifier.tsx`, `src/lib/notify.ts`)
- 근무 알림 기본 시각은 근무 전날 오후 9시, 모임 알림 기본 시각은 모임 전날 오전 9시입니다. 설정 탭에서 바꿀 수 있습니다. (`src/DutyNotifier.tsx` 10행, `src/lib/notify.ts`)
- 알림 설정 카드는 앱(안드로이드)에서만 보입니다. 웹에는 앱 알림이 없고, 대신 캘린더 파일(.ics) 추가 방식을 씁니다. (`src/screens/SettingsScreen.tsx` 102행)
- 백업: 설정 탭 > 데이터 > "내 기록 백업하기 (복사)". 복원: 같은 곳에서 "FIRESHIFT1:"로 시작하는 글자를 붙여넣고 "백업에서 복원하기"를 누릅니다. 백업 글자에는 **소모임 코드가 들어 있습니다.** (`src/lib/backup.ts`)
- 광고: 안드로이드 앱 화면 아래에 구글 배너 광고가 나옵니다. 맞춤 광고는 꺼 두었습니다. 웹에는 광고가 없습니다. **광고를 끄는 기능은 없습니다.** (`src/AdBanner.tsx`, `src/AdBanner.web.tsx`)
- 소모임 나가기: 팀 탭(또는 모임 탭) > 해당 소모임 칩 > ▼ 펼치기 > "이 소모임에서 나가기"를 두 번 누릅니다. 그러면 내 팀원 정보와 내 투표가 서버에서 지워집니다. (`src/screens/TeamScreen.tsx` 186–199행)
- 설정 탭의 "모든 기록 초기화"는 **폰 안의 기록만** 지웁니다. 서버의 팀원 정보는 지우지 않습니다. (`src/store.tsx` 144행)
- 소모임 초대 코드 확인: 팀 탭(또는 모임 탭)에서 소모임을 고르고 ▼를 펼치면 보입니다. 같은 소모임에 들어간 사람만 볼 수 있습니다. (`src/screens/TeamScreen.tsx` 275–276행)
- 탭 이름: 달력, 팀, 모임(모임에 들어가거나 켠 경우에만 보임), 설정. (`App.tsx` 21–24행)
- 근무 형태: 처음에는 3교대 기준으로 "내 팀"과 "오늘 상태"만 고르게 됩니다. "다른 근무 형태예요"를 누르면 일근, 2교대, 4조 2교대, 직접 입력(매달 직접 지정)을 고를 수 있습니다. (`src/SetupCard.tsx`)
- **구상 중이거나 계획이 없는 것 (답변에서 약속 금지):** 사진으로 근무표 넣기, 구독(유료), 경찰·해경·교정직 등 다른 직종, 아이폰 앱. 전화번호 수집과 "전화하기" 기능은 접었습니다. (`CLAUDE.md` 3–4장)

## 1. 문의 분류표

### 1-0. 한눈에 보기

| 종류 | 급함 | 한 줄 요약 |
|---|---|---|
| 기록이 사라짐, 복원 실패, 다른 사람 정보가 보임 | **긴급** | 팀장에게 즉시 보고. 답변은 접수 확인까지만 |
| 개인정보 삭제 요청 | **긴급** | 접수 확인 메일만 초안. 나머지는 팀장·대표 |
| 고장 신고 | 높음 (여러 명이면 긴급) | 증상 확인 후 안내 |
| 알림이 안 옴 | 보통 (여러 명이면 높음) | 설정 순서대로 점검 안내 |
| 기록 백업·복원 (방법 문의) | 보통 | 방법만 안내. 복원 문제는 팀장 |
| 소모임 코드 분실·오입력 | 보통 | 코드는 메일이나 리뷰에 적지 않음 |
| 사용법 질문 | 보통 | 메뉴 위치 안내 |
| 광고 불만 | 보통 | 광고 설명. 광고 제거·환불 약속 금지 |
| 기능 요청 | 낮음 | 접수 감사. 일정·가능 여부 약속 금지 |

### 1-1. 사용법 질문 (보통)
- **먼저 확인할 것**
  - 앱인지 웹인지, 폰 종류
  - 어느 탭·화면에서 막혔는지
  - 근무 형태(3교대 기본, 일근, 2교대, 4조 2교대, 직접 입력 중 무엇인지)
  - 소모임 관련 질문인지, 개인 달력 질문인지
- **답변 초안:** 초안 1
- **대표에게 넘길 조건**
  - 달력의 근무가 실제 근무와 다르다는 말이 나오면 팀장에게 넘깁니다. 설정 기준이 틀렸을 수도 있고, 계산 문제일 수도 있습니다.
  - "이런 기능이 되나요?"는 사용법이 아니라 기능 요청으로 분류합니다.

### 1-2. 고장 신고 (높음, 여러 명이면 긴급)
- **먼저 확인할 것**
  - 앱인지 웹인지, 폰 기종과 안드로이드 버전
  - 어떤 화면에서 어떤 행동을 했을 때 생겼는지, 언제부터인지
  - 같은 증상이 다시 나는지
  - 인터넷(와이파이, 데이터) 연결 상태
  - 오류 문구가 있다면 그대로 옮겨 적기 (예: "서버에 연결하지 못했습니다")
  - 화면 캡처 (개인정보가 보이면 가려서 받기)
- **주의:** 앱을 지우거나 다시 설치하라고 먼저 권하지 마세요. 폰 안의 기록이 사라집니다. 꼭 필요하면 백업을 먼저 하게 합니다.
- **답변 초안:** 초안 2
- **대표에게 넘길 조건**
  - 여러 명이 같은 증상을 말함
  - 앱이 켜지자마자 꺼짐 (이전에 있었던 문제입니다. 설치 파일 축소 설정(`app.json`의 `extraProguardRules`)을 지우면 다시 생길 수 있습니다.)
  - 소모임 자료가 전혀 안 보임 (서버 문제일 수 있음)
  - 기록이 사라진 것 같음 → 긴급

### 1-3. 기능 요청 (낮음)
- **먼저 확인할 것:** 원하는 것, 그렇게 쓰고 싶은 상황, 웹인지 앱인지. 같은 요청이 여러 번 들어왔는지 기록합니다.
- **답변 초안:** 초안 3
- **대표에게 넘길 조건 (대표 결정 필요)**
  - 돈을 내는 기능 (사진 근무표 넣기 등 구상 중인 유료 기능 포함)
  - 로그인, 회원가입
  - 전화번호 등 새 개인정보를 받는 기능
  - 다른 직종 확장, 아이폰 앱
  - 서버 구조를 바꾸는 기능
  - 전화하기 기능 요청 → 접었다고 답하되 팀장에게 알림
- 답변에서는 "넣겠다", "곧 된다", "될 것 같다"고 말하지 않습니다.

### 1-4. 개인정보 삭제 요청 (긴급)
- **먼저 확인할 것:** 요청 날짜와 종류만 기록합니다. 이름, 별명, 소모임 코드는 CS기록에 적지 않습니다.
- **즉시 조치:** 팀장에게 바로 보고합니다.
- **답변 초안:** 초안 4 (접수 확인만, 팀장·대표 승인 후 발송)
- **처리 절차:** 아래 3번 항목을 따릅니다.
- **대표에게 넘길 조건:** 항상. 서버 기록 삭제가 필요하면 **대표 승인 필요**.

### 1-5. 광고 불만 (보통)
- **먼저 확인할 것**
  - 어떤 광고인지 (내용, 화면 위치, 나온 시각)
  - 불편한 이유 (부적절함, 성인·자극적 내용, 자주 나옴, 화면 가림, 클릭이 잘못됨 등)
  - 웹인지 앱인지 (웹에는 광고 없음)
  - 캡처
- **답변 초안:** 초안 5
- **사실:** 광고는 구글 AdMob 배너입니다. 광고 내용은 광고주가 정합니다(`docs/이용약관.md` 6조). 맞춤 광고는 끄고 등급은 낮게(PG 이하) 요청합니다. 광고를 없애는 방법은 없습니다.
- **대표에게 넘길 조건**
  - 부적절하거나 불법인 광고를 신고할 때
  - 광고 때문에 앱이 멈추거나 꺼질 때 (1-2번 고장 신고로 옮김)
  - AdMob 계정, 수익, 정산 문의
  - 환불이나 보상 요구
- **주의:** 본인 광고를 클릭하지 않도록 안내하는 것은 사용자에게 할 말이 아닙니다. 부정 클릭 문제는 팀장이 관리합니다.

### 1-6. 소모임 코드 분실·오입력 (보통)
- **먼저 확인할 것**
  - 소모임 이름 (코드 자체는 묻지 않음)
  - 같은 소모임에 들어가 있는 동료가 있는지
  - 폰에 백업 글자가 있는지
  - 나온 오류 문구: "이 코드의 소모임을 찾을 수 없습니다" 또는 "서버에 연결하지 못했습니다"
- **코드를 찾는 방법:** 같은 소모임에 들어간 사람이 팀 또는 모임 탭에서 ▼를 펼치면 초대 코드가 보입니다.
- **주의**
  - 코드는 이메일이나 리뷰 답글에 **적지 않습니다.** 본인이라고 해도 보내지 않습니다.
  - 틀린 코드를 짧은 시간에 여러 번 넣으면 잠시 막힙니다. 막히면 "서버에 연결하지 못했습니다"만 보입니다.
- **답변 초안:** 초안 6
- **대표에게 넘길 조건:** 소모임이 사라졌다고 할 때, 백업 없이 팀원 정보를 되찾아 달라고 할 때, 다른 사람의 코드를 알려 달라고 할 때 → 팀장에게 넘김 (기록 복구와 코드 공개는 답하지 않음).

### 1-7. 기록 백업·복원 (보통, 기록이 사라졌으면 긴급)
- **먼저 확인할 것**
  - 백업 글자를 만들었는지, 어디에 보관했는지
  - 복원할 때 나온 문구: "백업 글자가 아닙니다", "중간에 잘린 것 같습니다" 등
  - 새 폰인지, 앱을 다시 설치했는지
- **답변 초안:** 초안 7 (백업하는 방법과 복원하는 방법만 안내)
- **대표에게 넘길 조건**
  - 복원이 안 되거나, 복원했는데 기록이 비어 있을 때
  - 백업 글자를 잃어버렸을 때
  - 다른 사람의 백업 글자로 복원해 달라고 할 때 (거절 대상, 팀장 보고)

### 1-8. 알림이 안 옴 (보통, 여러 명이면 높음)
- **먼저 확인할 순서**
  1. 앱인지 웹인지 (웹은 앱 알림이 없음)
  2. 설정 탭에 "알림" 카드가 보이는지 (안 보이면 앱 버전 확인)
  3. "근무 알림 켜짐 (누르면 끔)"으로 되어 있는지, 전날 몇 시로 되어 있는지
  4. 폰 설정에서 이 앱의 알림 허용이 켜져 있는지
  5. 절전 모드나 배터리 절약 기능이 켜져 있는지 (기기마다 메뉴 위치가 다름)
  6. 마지막으로 앱을 연 날짜 (14일 넘게 안 열었으면 그 뒤 알림이 없음)
  7. 모임 알림이라면, 앱을 열어 모임 일정을 받았는지 (서버에서 받은 뒤부터 울림)
- **답변 초안:** 초안 8
- **대표에게 넘길 조건:** 위 설정을 모두 맞춰도 안 옴, 여러 명이 같은 증상, 특정 기종에서만 안 옴 → 팀장에게 넘김.

## 2. 답변 초안 (9개)

> 모든 초안은 **대표 승인 전 발송 금지**입니다. 구글 플레이 리뷰 답글은 3문장 이내, 이메일은 조금 길게 썼습니다. 리뷰 답글에는 개인정보와 소모임 코드를 쓰지 않습니다.

### 초안 1. 사용법 질문: 근무 설정 방법

**구글 플레이 리뷰 답글**
> 안녕하세요, 소방 교대달력입니다. 설정 탭에서 근무 형태를 고르고 오늘 상태를 고르시면 달력에 근무가 바로 채워집니다. 더 자세한 방법은 eosqaws1@gmail.com으로 보내 주시면 안내해 드리겠습니다.

**이메일 답변**
> 제목: [소방 교대달력] 근무표 설정 방법 안내
>
> 안녕하세요. 소방 교대달력을 써 주셔서 감사합니다.
> 처음 설정은 아래 순서로 하시면 됩니다.
>
> 1. 아래쪽 메뉴에서 [설정]을 누르세요.
> 2. 처음 화면에서 내 팀과 오늘 상태를 고르세요. 근무 형태가 다르다면 "다른 근무 형태예요"를 누른 뒤 일근, 2교대, 4조 2교대 중에서 고르시면 됩니다. 목록에 없으면 직접 입력하는 방법도 있습니다.
> 3. 설정을 마치면 [달력] 메뉴에서 이번 달 근무가 채워진 것을 보실 수 있습니다. 달력은 좌우로 밀면 다음 달로 넘어갑니다.

**중요한 점**
- "모든 기록 초기화"만 누르면 **서버의 팀원 정보는 남습니다.** 소모임 정보까지 지우려면 "나가기"를 먼저 해야 합니다.
- 나가기 요청이 실패해도 앱은 조용히 넘어갑니다 (`src/screens/TeamScreen.tsx` 191행, `.catch(() => undefined)`). 그래서 나가기가 실제로 서버에서 됐는지 앱만 보고는 알 수 없습니다. (확인 필요)
- 앱을 지워도 서버의 팀원 정보는 남습니다. 폰에만 내 번호표가 있기 때문입니다. 이 점은 방침에 아직 자세히 적혀 있지 않습니다. (확인 필요)

### 3-4. 서버 기록을 직접 지워야 하는 경우 — **대표 승인 필요**
- 요청자의 폰이 없거나 앱을 지워서 나가기를 할 수 없을 때
- 나가기를 했는데도 서버에 기록이 남아 있을 때 (확인 필요)
- 다른 사람이 만든 투표 제목 등에 개인정보가 들어 있을 때
- 이때 CS부는 서버를 직접 바꾸지 않습니다. 팀장이 대표 승인을 받은 뒤, 지울 대상과 방법(삭제 함수를 쓸지, 표의 행을 지울지)을 정해서 처리합니다.
- 처리 전에 백업을 준비합니다 (전역 `CLAUDE.md` 6장).
- 삭제 전에 확인할 것: 대상이 정말 요청자의 기록인지, 같은 소모임의 다른 사람 기록이 섞이지 않는지.

### 3-5. 처리 후 답변 (대표 승인 후 발송)
- 무엇을 지웠는지 구분해서 적습니다: 폰 기록 / 서버의 팀원 정보 / 투표.
- 남는 것을 알려 줍니다: 사용 횟수 합계(개인 식별 불가), 소모임 자체(이름과 코드), 다른 사람이 만든 투표 내용(있다면).
- 처리한 날짜를 적습니다.
- 처리 기한은 방침에 정해져 있지 않습니다. (확인 필요: 대표가 정함)

## 5. 문의 접수 창구: 구글 플레이 리뷰 vs 이메일

### 5-1. 비교

| 항목 | 구글 플레이 리뷰 | 이메일 (eosqaws1@gmail.com) |
|---|---|---|
| 누가 보나 | 누구나 볼 수 있음 (공개) | 나와 보낸 사람만 봄 (비공개) |
| 개인정보 노출 | 위험이 큼 | 상대적으로 안전 |

| 본인 확인 | 어려움 | 답장 주소로 어느 정도 가능 (완벽하지 않음) |

| 스팸 | 적은 편 | 많을 수 있음 |

### 5-2. 장단점

**구글 플레이 리뷰**
- 장점
  - 사용자가 이미 쓰는 곳이라 발견하기 쉽습니다.
  - 공개 답글로 불안한 사용자에게 성의를 보여 줄 수 있습니다.
  - 추가 도구 없이 쓸 수 있습니다.
- 단점
  - 개인정보나 소모임 정보를 다른 사람이 볼 수 있습니다.
  - 답글 글자 수가 짧아서 상세한 답변이 어렵습니다.
  - 출시 전에는 쓸 수 없습니다.
  - 리뷰 내용은 사용자가 나중에 고치거나 지울 수 있어 기록으로 남기기 어렵습니다.

**이메일**
- 장점
  - 비공개라서 개인정보나 기록 문제를 다루기 좋습니다.
  - 캡처를 받을 수 있고 답변을 길게 쓸 수 있습니다.
  - 답장 주소로 요청자를 어느 정도 확인할 수 있습니다.
  - 기록이 메일함에 남습니다.
- 단점
  - 주소가 개인 메일이고 이미 여러 문서에 공개되어 있어 스팸이 올 수 있습니다.
  - 메일을 확인하고 답하는 시간을 내야 합니다.
  - 사용자가 메일을 보내는 습관이 적을 수 있습니다.
  - 보낸 사람이 다른 사람인 척할 수 있어서 본인 확인에 한계가 있습니다.

### 5-3. 추천안 (대표 결정 필요)
1. **기본 창구는 이메일로 합니다.** 개인정보, 기록, 코드, 자세한 문제는 이메일로만 받습니다.
2. **리뷰는 짧은 안내 용도로만 씁니다.** 답글은 초안 1~8의 리뷰 문구를 쓰고, 리뷰 답글에는 개인정보를 쓰지 않습니다. 리뷰에 개인정보가 올라오면 대표가 콘솔에서 신고할지 정합니다. (확인 필요)
3. **메일 분류는 Gmail 기본 라벨과 필터로만 합니다.** 라벨 예: "CS-긴급", "CS-개인정보", "CS-일반". 새 고객센터 도구는 추가하지 않습니다 (전역 `CLAUDE.md` 2장).
4. **대표가 정할 것**
   - 리뷰 답글을 누가 올리고, 몇 시간 안에 답할지
   - 메일 응답 목표 시간
   - 메일 계정의 2단계 인증 설정
   - 자동 답장 문구 (Gmail 기본 기능으로 가능, 추가 비용 없음)
5. **앱 안에 문의 링크는 아직 없습니다.** 설정 탭의 "안내" 카드에는 방침과 약관 링크만 있습니다(`SettingsScreen.tsx` 146–150행). 문의 메일 링크를 넣으려면 앱 빌드가 한 번 더 필요합니다. 제안만 하고, 넣을지는 대표가 정합니다.
