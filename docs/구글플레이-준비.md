# 구글 플레이 준비 (초안)

> 구글 공식 문서를 직접 읽고 쓴 것이 아닙니다. 콘솔 화면의 질문 문구가 다르면 화면을 기준으로 고치고, 이 문서도 같이 고치세요.

## 1. 순서
1. 개발자 계정 가입 (한 번 25달러, 대표님이 직접 결제·본인 인증)
2. 앱 만들기 (앱 이름, 기본 언어 한국어, 앱 유형 "앱", 무료)
3. 비공개 테스트 트랙 만들고 **테스터 이메일 목록**(12명 이상, 여유 있게 15~20명) 등록
4. AAB 파일 올리기 (아래 3번)
5. 테스터가 참여 링크로 설치 → **14일 연속** 참여 유지
6. 14일 뒤 "프로덕션 액세스 신청" → 심사 → 출시
7. 출시 후 AdMob 앱 심사(보통 2~3일)가 통과되면 광고 제한이 풀림

## 2. 앱 정보
- 패키지 이름: `kr.fireshift.app` (한 번 올리면 바꿀 수 없음)
- 개인정보처리방침 주소: https://fire-shift.fire-shift-app.workers.dev/privacy.html
- 문의 이메일: eosqaws1@gmail.com
- 스토어 설명 문구 초안: `docs/스토어등록-문구.md`
- 앱 아이콘 512×512, 대표 이미지 1024×500, 휴대폰 스크린샷 최소 2장(비율 제한 있음)이 필요합니다. 스크린샷은 실제 폰 화면을 찍어서 만듭니다.

## 3. 올리는 파일(AAB)
- 지금 쓰는 APK는 동료 테스트용입니다. 구글 플레이에는 **AAB**를 올립니다.
- `eas.json`의 `production` 프로필이 안드로이드에서는 기본으로 AAB를 만듭니다. 빌드 명령:
  `npx.cmd eas-cli build --platform android --profile production`
- 앱 서명: 구글 플레이 "앱 서명" 방식을 쓰면, EAS가 가진 키는 "업로드 키"가 됩니다. 올리기 전에 EAS에서 키 정보를 백업하세요.
- 버전 번호는 `autoIncrement`가 자동으로 올립니다.

## 4. 데이터 보안 설문 (방침과 똑같이 적기)
앱 동작 기준 초안입니다. 화면 질문 순서에 맞춰 고르세요.

| 항목 | 답 | 이유 |
|---|---|---|
| 데이터 수집 여부 | 예 | 별명·일정을 서버에 저장 |
| 데이터 암호화(전송 중) | 예 | 서버 통신은 HTTPS |
| 삭제 요청 방법 제공 | 예 | 앱에서 삭제 가능, 이메일 문의 |
| 개인 정보 → 이름 | 수집(이용자가 입력한 별명) | 소모임 팀원 표시용. 선택 입력, 제3자에 판매·공유 안 함 |
| 앱 활동 → 앱 상호작용 | 수집(사용 횟수 합계) | 개인을 알아볼 수 없는 합계만 |
| 기기 또는 기타 ID → 광고 ID | 수집, **공유(광고: 구글 AdMob)** | AdMob 광고 표시 |
| 위치, 연락처, 사진, 결제 정보, 건강 정보 | 수집 안 함 | 해당 기능 없음 |
| 로그인·계정 | 없음 | 회원가입 없음 |

확인 필요:
- 서버 업체(Supabase)에 저장하는 것을 "공유"로 볼지 "서비스 제공자 처리"로 볼지는 콘솔 안내 문구를 읽고 정하세요.
- 알림은 폰 안에서만 예약하므로 서버로 보내는 정보가 없습니다. 푸시 서버를 새로 쓰게 되면 이 표를 고쳐야 합니다.

## 5. 앱 콘텐츠 신고
- 광고: **광고 포함** 으로 신고
- 대상 연령: 만 18세 이상 (어린이 대상 아님)
- 콘텐츠 등급 설문: 폭력·성적·도박 내용 없음으로 답변. 사용자 간 소통은 이름·일정·투표뿐이며 자유 글 입력이 있는지 코드를 보고 확인한 뒤 답하세요.
- 정부 앱, 금융, 건강, 뉴스 앱: 모두 아님
- 광고 ID 사용 선언: 사용함(광고 목적)

## 6. 테스터에게 부탁할 것
- 구글 계정(지메일 등) 이메일 알려 주기. 이메일 목록은 채팅이나 코드에 남기지 말고 콘솔에만 넣는다.
- 참여 링크의 **참여** 버튼을 누르고 설치
- 14일 동안 참여 취소 금지, 가끔 앱 열기

## 7. 출시 뒤 확인
- AdMob 앱이 "준비 중"에서 풀리는지 확인
- 광고가 안 나오면 최대 1시간~며칠 기다린 뒤 AdMob 안내 확인
- `app-ads.txt` 안내가 나오면 따르기 (개발자 웹사이트 주소가 필요할 수 있음)
